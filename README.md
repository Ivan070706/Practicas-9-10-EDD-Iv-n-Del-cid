## 📂 Contenido del Repositorio

* **`ejercicio1`**: Código original de la clase `Rectangulo` y las pruebas de JUnit 5. Incluye los tests de valores positivos, negativos, ceros y el test erróneo a propósito para ver cómo falla la barra de JUnit.
* **`ejercicio2`**: Informe de cobertura generado con el plugin EclEmma de Eclipse donde se muestra que el juego de pruebas cubre el 100% del código.
* **`ejercicio3`**: Archivo PDF con las capturas de pantalla del análisis de SonarLint en Eclipse y una breve explicación de las diferencias con SonarQube.
* **`ejercicio4`**: Segunda versión del código refactorizado. Se ha pasado todo al inglés (`Rectangle`, `surface`, `perimeter`), se ha creado la constante para el número 2 y se ha extraído el método `validarDimensiones` para no repetir código.
* **`ejercicio5 (Carpeta /doc)`**: Documentación de la clase generada automáticamente con Javadoc, incluyendo las etiquetas de autor, versión, parámetros y devoluciones. Se puede ver abriendo el archivo `index.html`.
